# Contributing

Thank you for considering contributing to this project! 🎉

## Reporting Bugs

1. Check the "Troubleshooting" section in the README and the open issues.
2. Create an issue using the **Bug report** template and include:
   - application and PySide6 versions;
   - OS and Python version;
   - the error text from the Operation Log;
   - if possible, an anonymized fragment of the JSON export.

## Suggesting Features

Create an issue using the **Feature request** template describing
the problem and the desired outcome.

## Pull Requests

1. Fork the repository and create a branch from `main`:
   `git checkout -b feature/my-feature`
2. Follow the project code style (PEP 8, 4-space indentation, docstrings).
3. Make sure the app launches and converts both formats correctly.
4. Describe your changes in the PR and link the related issue.

## Commit Convention

Use clear messages in the form:
`type: short description` — e.g. `fix: parse empty Qwen phases`.
Types: `feat`, `fix`, `docs`, `refactor`, `chore`.
